# Projects Page Copy / Rules

## Hero
**Work That Should Speak for Itself.**

Use this page only for real JKJ projects, installations or digital work that the company is authorised to display.

## Case study structure
Each project should contain:
- service category
- city / region
- client type (not client name unless approved)
- challenge
- scope
- solution
- outcome
- 3–8 real photographs/screenshots
- optional testimonial only with permission

## Until real cases are ready

Instead show:

For web/graphic-design work, real portfolio links can be added once confirmed.

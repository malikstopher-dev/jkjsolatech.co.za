This pack is prepared as a **rebuild/upgrade handoff for Mimo**, followed by a smaller review pass in Sol.

## Important credibility rule

Do **not** invent or retain unsupported claims such as:
- project/client counts
- satisfaction percentages
- “10+ years” experience
- 24/7 emergency availability
- “certified team”
- named brand partnerships
- DRC offices, DRC employees, DRC completed projects
- testimonials presented as real unless the company can verify them

Use only real information or clearly label content as capability, planned expansion, or project availability.

## Recommended workflow

1. Give Mimo the whole existing project plus this upgrade pack.
2. Give Mimo `prompt/MIMO_MASTER_PROMPT.md`.
3. Let Mimo implement the rebuild completely.
4. Run locally and verify every page at desktop, tablet and mobile widths.
5. Then give Sol `prompt/SOL_FINAL_AUDIT_PROMPT.md` for a focused polish/QA pass.

## Folder guide

- `assets/desktop/` — wide service/hero assets, 1600×900 WebP
- `assets/mobile/` — portrait mobile assets, 900×1200 WebP
- `assets/thumbnails/` — service/card images, 800×600 WebP
- `assets/brand/` — transparent logo derivatives
- `assets/concepts/` — concept boards/posters; **reference only, not to be used as page backgrounds without checking for baked-in text**
- `content/pages/` — page copy
- `content/services/` — service copy and SEO
- `architecture/` — sitemap, layout and asset map
- `audit/` — current-site findings and cleanup rules
- `prompt/` — Mimo implementation prompt + Sol audit prompt

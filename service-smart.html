What We Offer

Our Smart Automation Services

JKJ Solartech and Security installs and configures smart automation systems for compatible lighting, plugs, blinds, curtains, climate controls and selected security devices. Controls can be organised by room, device group, schedule or scene.

System planning covers the required controls, compatible hubs and applications, user access and automation rules. Existing supported devices can be incorporated where their platforms and communication standards allow integration.

Services Include:

  • Smart lighting switches, dimmers and control modules
  • Smart plug and appliance control setup
  • Automated blind, curtain and shade controls
  • Smart thermostat and climate control integration
  • Motion, door, temperature and environmental sensor setup
  • Room groups, scenes, schedules and automation routines
  • Supported smart hub and mobile application configuration
  • Compatible voice assistant integration
  • Selected smart lock, intercom and camera controls
  • Existing automation system expansion and fault diagnosis
